# Signature

The signature field can be used to draw and save a signature, say to sign off a feature or a record. Signature field requires a field with `Text (string)` data type.

:::tip Example project available
Signature field is used in this public project <MerginMapsProject id="documentation/form-widgets" />. Download or clone it to see the setup.
:::

## Signature field setup

To set up the signature field, the field name or the field alias must contain the word `signature`. The text is not case-sensitive and can use any combination of uppercase and lowercase letters.

The <MobileAppNameShort /> displays the signature field. Tap it to draw a signature and save your changes. The signature is saved as an image. It can be removed or replaced by a new signature.
